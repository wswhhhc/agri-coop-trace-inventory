# 前端 UI 增量开发记录

## 当前状态

- 业务前端 F01-F38 已完成，当前进入视觉和交互统一阶段。
- 设计定位：现代农业数字化运营平台。
- 当前阶段：准备开始 UI06 数据组件。
- 本阶段暂不修改业务 API 和权限逻辑。

## 已确认设计决策

- 支持浅色、深色、自动三种主题。
- 自动模式跟随系统；手动选择持久化并覆盖系统设置。
- 采用农业绿、米白、深墨绿和稻穗金组成的现代自然主义配色。
- 优先完成设计令牌、主题机制和公共组件，再逐组改造业务页面。
- 页面优先保证信息层级和可操作性，样式装饰服从库存、预警、追溯等业务重点。

## 完成记录

### UI01 设计令牌与主题变量

- 实现：新增 `frontend/src/styles/tokens.css`，建立农业绿、米白、深墨绿、稻穗金、语义状态色、间距、字体、圆角、阴影和动效令牌；预置浅色、深色及系统主题变量；在 `main.ts` 接入全局样式入口。
- 测试：前端全量测试 23 个文件、71 项通过；`pnpm build` 通过；`git diff --check` 通过。
- 复查：确认本切片没有修改业务页面、接口或权限逻辑；组件后续只应使用语义变量，不直接写页面级颜色。
- 提交：`9c468e9 feat: 建立前端UI设计令牌`

### UI02 浅色/深色/自动主题切换

- 实现：新增 `useTheme` 主题工具和 `ThemeSwitcher`；支持浅色、深色、自动三种选择，保存到 `localStorage`，监听系统深色模式变化，并在应用挂载前初始化 `data-theme`。
- 测试：主题工具 7 项聚焦测试通过；全量测试 24 个文件、78 项通过；`pnpm build` 通过；`git diff --check` 通过。
- 复查：确认主题状态与业务权限解耦，当前只在顶部栏增加最小选择控件，未提前改造页面布局；测试使用内存 Storage，避免依赖 Node 实验性 localStorage。
- 提交：`b957348 feat: 增加前端三主题切换`

### UI03 全局基础样式

- 实现：新增全局基础样式，统一页面背景、正文、链接、按钮、输入框、选择框、表格、代码块、焦点环、禁用状态和减少动效规则，并接入 `main.ts`。
- 测试：全量测试 24 个文件、78 项通过；`pnpm build` 通过；`git diff --check` 通过。
- 复查：确认本切片未引入页面级布局和业务组件样式；交互控件保持键盘可操作，焦点不依赖颜色单独表达。
- 提交：`46a44e6 feat: 增加前端全局基础样式`

### UI04 现代化 AppShell

- 实现：改造侧栏品牌区、顶部栏上下文、面包屑和内容容器；新增移动端侧栏开关、遮罩关闭、当前路由标题和响应式布局。
- 测试：全量测试 24 个文件、78 项通过；`pnpm build` 通过；`git diff --check` 通过。
