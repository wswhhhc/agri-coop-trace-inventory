# 前端 UI 增量开发记录

## 当前状态

- 业务前端 F01-F38 已完成，当前进入视觉和交互统一阶段。
- 设计定位：现代农业数字化运营平台。
- 当前阶段：等待开始 UI01 设计令牌与主题变量。
- 本阶段暂不修改业务 API 和权限逻辑。

## 已确认设计决策

- 支持浅色、深色、自动三种主题。
- 自动模式跟随系统；手动选择持久化并覆盖系统设置。
- 采用农业绿、米白、深墨绿和稻穗金组成的现代自然主义配色。
- 优先完成设计令牌、主题机制和公共组件，再逐组改造业务页面。
- 页面优先保证信息层级和可操作性，样式装饰服从库存、预警、追溯等业务重点。
