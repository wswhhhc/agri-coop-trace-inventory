# 前端增量实施计划

## 目标

按照“少量、多次、每次可运行”的方式，补齐前端业务模块。每个任务只完成一个垂直切片，完成后必须测试、复查、记录并提交 Git。

## 每个任务的完成标准

- API 类型、请求方法和页面交互完整。
- 页面至少能完成真实接口调用、加载、空数据、错误和成功状态。
- 新增行为有对应 Vitest 测试；必要时补充浏览器手工验证。
- `pnpm test`、`pnpm build` 通过。
- 复查范围、权限、错误处理和重复提交风险。
- 更新本文件和 `tasks/frontend-progress.md`，使用中文 Git 提交说明。

## 范围约束

- 暂不投入视觉样式，优先使用现有页面组件和原生表单/表格。
- 不提前建设未被两个以上功能验证需要的通用抽象。
- 不覆盖工作树中已有的用户修改。
- 后端缺失的角色/权限接口单独记录为依赖，不用猜测性请求替代。
