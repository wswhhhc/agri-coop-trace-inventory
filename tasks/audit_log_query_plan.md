# 审计日志查询接口执行书

## 目标

完成只读 `GET /audit-logs` 和 `GET /audit-logs/{auditLogId}`，确保分页、`audit:read` 功能权限、合作社数据范围、仓库工作人员仅本人范围，以及审计字段脱敏均可验证。

## 范围与约束

- 仅新增审计日志查询链路（Schema、Repository、Service、API、测试、接口文档）。
- 不新增、修改、删除审计日志接口；不改变审计写入行为。
- 复用现有分页响应、认证上下文、异常语义和事务边界；无自然复用点时保持模块职责清晰。
- `detail` 响应按递归敏感键规则脱敏，IP 地址和 User-Agent 不对外返回。

## 阶段

| 阶段 | 内容 | 状态 | 验收 |
|---|---|---|---|
| 1 | 冻结契约并编写 RED 测试 | 已完成 | 覆盖分页、权限、范围、脱敏、详情不可见 |
| 2 | 实现只读查询链路 | 已完成 | Schema/Repository/Service/API 接通且无写操作 |
| 3 | 阶段复查与提交 | 已完成 | 聚焦测试、Ruff、mypy、暂存差异复查、中文 Git 提交 |

## 已知契约

- 权限码：`audit:read`。
- 系统管理员可查询全局；合作社管理员仅本合作社；仓库工作人员强制为当前用户本人。
- 越权或不可见详情统一返回 `404 RESOURCE_NOT_FOUND`；无功能权限返回 `403 PERMISSION_DENIED`。
- 查询参数：`userId`、`action`、`resourceType`、`resourceId`、`result`、`startDate`、`endDate`、分页参数。
