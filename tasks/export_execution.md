# export 模块任务执行书

## 目标

完成报表导出后端模块：合作社管理员提交异步 Excel 导出任务，按本合作社和可选仓库、日期范围生成库存明细或预警明细报表；任务状态复用 `task_records`，成功后提供短时有效下载地址，失败记录错误信息。

## 依据与假设

- 以《软件需求规格说明书》FR-RPT-004 和《接口设计说明书》第 16.2 节为接口与验收依据。
- 支持 `INVENTORY_DETAIL`、`ALERT_DETAIL` 两种报表类型；两者均支持 `warehouseId`、`startDate`、`endDate` 筛选。
- `startDate`、`endDate` 未提供时默认最近 30 个自然日，最大范围 366 天，结束日期不得早于开始日期。
- 仅 `COOPERATIVE_ADMIN` 可以提交导出任务；库存报表要求 `inventory:read`，预警报表要求 `alert:read`。
- 查询必须在 Repository SQL 条件中执行合作社和仓库范围过滤；不依赖导出后再过滤，避免越权文件生成。
- 导出文件写入受控本地存储目录，下载接口再次校验任务发起人/合作社范围和过期时间；不把数据库密码或其他凭据写入代码。
- 复用现有 `TaskRecord`、`TaskData`、事务边界、认证上下文和 Celery 配置；仅在确有共享价值时抽取公共逻辑。
