# 数据库基础实施计划

## 概述
依据已批准的需求和接口契约，建立PostgreSQL数据库基础。本轮只覆盖数据库设计、迁移、结构SQL和合成演示数据，不实现业务API。

## 架构决策
- Alembic初始迁移是数据库结构的真实来源，并提供完整downgrade。
- `schema.sql`与迁移保持相同建表顺序，供人工审阅和答辩展示。
- 库存通过操作头、当前库存和不可变流水三层表达。
- 多租户实体显式保存`cooperative_id`并配置组合索引。
- 合成数据生成器使用固定种子，输出可重复导入的SQL。

## 风险与缓解
| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 本机无PostgreSQL服务 | 无法在线执行迁移 | 使用Alembic离线编译，并保留后续容器集成测试任务 |
| 初始表过多 | 实现范围膨胀 | 本轮只建结构和演示数据，业务实现按能力模块分批完成 |
| 合成数据被误认为真实数据 | 学术诚信风险 | 文件头、文档和数据中显式标注SYNTHETIC |
| schema.sql与迁移漂移 | 后续执行错误 | 以迁移为真实来源，并做对象名称静态对比 |
