# 数据库基础任务清单

- [x] D1 统一需求与接口中的数据库决策
  - 验收：刷新令牌、AI粒度、附件和调拨优先级描述一致。
  - 验证：使用 `rg` 检查旧描述不再存在。

- [x] D2 编写数据库设计说明书
  - 验收：包含ER图、表字段、外键、约束、索引和数据安全说明。
  - 验证：核心接口中的实体全部可以映射到表。

- [x] D3 初始化Alembic
  - 验收：配置从环境变量读取数据库URL，支持离线SQL。
  - 验证：`uv run alembic upgrade head --sql` 成功。

- [x] D4 编写初始迁移
  - 验收：全部表、约束和索引可升级并有逆序回滚。
  - 验证：离线SQL包含建表与删除表语句。

- [x] D5 提供schema.sql
  - 验收：结构与迁移对象一致，不包含演示数据。
  - 验证：静态比较表和索引名称。

- [x] D6 先编写生成器测试
  - 验收：测试覆盖固定种子、数据数量、标识和依赖顺序。
  - 验证：实现前测试因模块不存在而失败。

- [x] D7 实现合成数据生成器
  - 验收：固定种子生成多合作社、仓库、用户、产品、批次、库存、预警和预测数据。
  - 验证：相同种子输出完全相同，不同种子输出不同。

- [x] D8 生成并验证demo_data.sql
  - 验收：SQL明确标注合成数据，可重复清理和导入。
  - 验证：Pytest、Ruff及结构检查通过。
