# 合成演示数据说明

## 1. 数据性质

`sql/demo_data.sql` 中的合作社、人员、地址、批次、库存、质检、预警和预测结果全部为虚构合成数据，仅用于毕业设计展示、接口联调和自动化测试，不代表任何真实经营情况。

- 固定随机种子：`20260904`
- 数据基准时间：`2026-09-04 09:00:00+08:00`
- 重复生成结果一致，可用于复现实验。
- SQL 使用确定性 UUID 和 `ON CONFLICT DO NOTHING`，可在同一套演示数据上重复导入。

## 2. 数据规模

| 数据 | 数量 |
|---|---:|
| 合作社 / 仓库 | 2 / 4 |
| 后台用户 | 7 |
| 产品分类 / 产品 | 4 / 8 |
| 批次 / 质检记录 / 质检项目 | 24 / 24 / 72 |
| 当前库存 | 16 |
| 90天库存操作 / 流水 | 1456 / 1456 |
| 追溯事件 | 64 |
| 预警规则 / 预警 | 16 / 12 |
| Celery任务记录 | 32 |
| 模型版本 / 预测结果 / 每日预测点 | 16 / 16 / 112 |
| 审计日志 | 20 |

90天历史出库数据覆盖16个“仓库＋产品”组合，可用于移动平均、随机森林或XGBoost的训练与对比演示。

## 4. 配置数据库

打开项目根目录的 `.env`，只需把本机 PostgreSQL 密码写在等号后：

```dotenv
POSTGRES_PASSWORD=你的数据库密码
```

`.env` 已被 Git 忽略，不会提交。不要把密码写入 `.env.example`、Python代码、SQL文件或提交记录。

## 5. 初始化与导入

先创建名为 `agri_trace` 的专用开发数据库，然后在项目根目录执行：

```powershell
uv run alembic upgrade head
& 'D:\PostgreSQL\bin\psql.exe' -W -h localhost -U postgres -d agri_trace -f 'sql\demo_data.sql'
```

`-W` 会在终端中安全提示输入密码。若 PostgreSQL 安装路径不同，请把 `psql.exe` 路径改为本机实际路径。

## 6. 重新生成

```powershell
uv run python -m scripts.generate_demo_data --seed 20260904 --output sql/demo_data.sql
```

可以更换随机种子生成另一套虚构数据，但论文实验和自动化测试建议继续使用默认种子，以保证结果可复现。

## 7. 局限性

- 数据分布是人为设计的季节性和周末波动，不代表真实农产品销量规律。
- AI指标与预测结果是展示数据，后续实现训练流程时应重新计算并写入数据库。
- 虚构质检异常仅用于验证预警流程，不具备食品安全结论效力。
